# Student Performance Predictor

## Project Overview
This project uses machine learning techniques to predict student final grades based on academic, social, and lifestyle factors.

The project demonstrates:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Regression machine learning models
- Model evaluation and comparison

---

Dataset
Dataset used:
UCI Student Performance Dataset

Source:
https://archive.ics.uci.edu/ml/datasets/Student+Performance

---

 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---
 Machine Learning Models
  1. Linear Regression
Used as the baseline regression model.

  2. Random Forest Regressor
Used to improve prediction performance and compare results.

---

 Project Workflow
1. Data loading
2. Data cleaning
3. Exploratory Data Analysis
4. Correlation analysis
5. Feature encoding
6. Train-test split
7. Model training
8. Model evaluation
9. Visualization of results

---

Visualizations
The project includes:
- Grade distribution histogram
- Study time vs grades boxplot
- Correlation heatmap
- Feature importance chart
- Model comparison chart
- Actual vs predicted grades scatterplot

---

 Results
The Random Forest model achieved better prediction accuracy compared to Linear Regression.

Evaluation metrics used:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
